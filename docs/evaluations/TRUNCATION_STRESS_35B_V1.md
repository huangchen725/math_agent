## 边界与下一步

1. 本压力集题面长度和推导要求显著高于旧公式型 smoke set，但仍是项目自建题，无法复现隐藏集全部难度、提示分布和判分规则。
2. 0 截断说明主动长度控制在本集生效，不等于所有未来请求都不会截断。恢复状态机必须继续保留，不能因本次 0 事件删除。
3. 下一次 112 题官方隐藏集仍是最终验证。若请求数约 1082，截断最多允许 42 次，并要求逐题 `invalid=0`；最好取得逐题配对结果后再判断正确率变化。
4. 若官方截断仍超过门禁，只按分阶段统计调整对应 prompt，不同时改变候选数、温度、聚合或模型。
