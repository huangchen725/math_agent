## 3. C1 能力边界和实用覆盖

支持 1–6 阶方阵、整数或有理数字符串（JSON 浮点和布尔量拒绝）、受限 LaTeX 矩阵；多项式变量仅 x，次数最多 12、AST 最多 64 节点、系数位数有界。输入任务与答案各最多 1200 字符，内部多项式表达式最多 128 字符。组合数 n≤1000、模幂指数≤10^6，数值字面量绝对值≤10^9。大结果、未知函数、附加条件、复合任务及不完整表达式保留 unknown。

不定积分必须含显式 `+C` 才能获得完整通过。单根代入、局部等式、有限采样一致不会被包装成整题证明；没有新增通用符号求解器或任意代码执行。

测试使用与实现不同的排列展开行列式 oracle、积分/导数逆关系及条件/资源反例。固定候选池验证“一个精确正确候选胜过错误多数”、错误紧急补答被拒绝，不额外调用模型。

对既有 72 道公开开发题进行仅输入的完整解析探针，覆盖 **0/72**。这说明当前题面语法和数学原语范围很窄；C1 的受限正确性测试通过不能换算成这套题的准确率收益。记录：`outputs/first-batch-20260908/c1-public-coverage.json`。

## 6. 判分争议与后续决策

B2 的积分参考式含错误的根号常数。原题 Q=25x²+10x+6=(5x+1)²+5；新补答 `sqrt(Q)/25 + 9/25*ln(5x+1+sqrt(Q))+C` 求导严格等于原被积函数。旧补答在 x=1 的导数误差为 `4/sqrt(41)`；公开参考在 x=0 的误差为 `-3*sqrt(6)/10+9*sqrt(2)/10`。SymPy 1.14 的独立核对和原始反例在 `math-receipt-checks.json`，不改冻结标签，未宣称完成双人盲审。

C2a 的级数题 `sum p^(n^2)/2^n` 未声明 p>0，正确收敛域为 |p|≤1；公开参考仅写 p≤1，遗漏负侧边界，p=-2 即反例。新答案 |p|<sqrt(2) 也错误，p=5/4 即反例。另一道参数积分的新答在 x=0 的导数误差为 -17/1296，旧答导数残差严格为零。

还观察到既有路由把英文不等式题分到复分析（生成提示含该领域策略）。本批未改路由，不将这一观察泛化为全部数学错误的根因；应在后续路由/领域改进中用固定词界反例核查。无标记 boxed 答案属于交付资格损失，应单独研究有界兼容，不能为抢救一个样例全面放宽提取器。

本批继续关闭全部实验开关。检索应先改善数学术语、公式结构和题族隔离后的实际覆盖；计算线应先扩展可完整绑定条件的题面与任务覆盖。B1/B2/C2a 是否继续或晋级，以最终小批结果和后续端到端证据决定，不能用本地测试数或一小批收益保证正式提分。
