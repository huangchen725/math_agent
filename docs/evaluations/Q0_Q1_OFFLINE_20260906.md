## Q1 实现与消融

`Q1Policy` 的五个字段默认均为 False，显式 `local_policy` 才能开启。正式三参数 client、根入口物理声明和五文件正式闭包保持不变；不会探测或读取注入 client 的私有能力。

| 实验 | 已实现行为 | 离线可证明的部分 |
| --- | --- | --- |
| recover_plain | 为缺少完整答案的纯推理候选增加预算内直接恢复 | 有合格兄弟候选时仍可恢复；截断/异常恢复不复活残文；请求共用原预算 |
| deterministic | 完整题型上的精确 pass 优先，精确 fail 不参与聚合，unknown 保留原顺序 | 整数/有理算式、组合数、模幂、有界多项式导数/积分、小矩阵行列式；多问或不支持语法不作证明 |
| compact_routing | 紧凑领域检查提示替换长领域 prompt | 不包含参考答案、不新增请求；是否提高成绩待真实比较 |
| calibrated_verifier | 严格识别唯一 VERDICT A/B，矛盾/多余文本/截断为 unknown | unknown 不变成 fail，不单独触发 critic；截断有独立状态事件 |
| diverse_candidates | 纯推理候选增加独立方法要求，温度在实验内增加 0.2、上限 1.0 | 不改变共享配置或候选数；增加的是明确待评估变量 |
| no_critic / no_reflection | 分别关闭 critic 链和仅关闭 reflection | 开关真实生效，二者不再意外成为同一消融 |
| no_tools | 通过既有 enable_tools 关闭工具路径 | 可在显式本地适配器计划中与工具候选比较，不冒充正式平台工具能力 |
| combined | 五项实验组合 | 仅作为候选；不将组合结果归因为单个改动 |

连同 baseline 共十组。每个单项与 baseline 的配置差异恰好一项；全部十组已用严格模拟 client 完成端到端运行测试。另验证显式本地适配器的工具协议计划及元数据记账，禁止与正式文本协议混配。

确定性数学模块采用纯标准库、有界 AST 和 Fraction，不使用 eval/exec 或动态外部工具，不把题目中的一段算式当成完整题意。积分必须给出完整的 `+C` 形式；自然语言多问、变量分母、三角/对数函数或超界表达式均 unknown。一般方程的一个根不是完整解集证明，旧 verify_equation_solution 原语未被直接用于提高候选权重。

生成的开发集计划：`outputs/q0-q1-final/r2/dev-plan.json` 与 `local-tools-plan.json`。每个候选 72 题，最多 1152 次 Agent 层请求；十组全跑的上限为 11520 次，各候选不自动执行。该上限不是 HTTP 重试数或货币费用估计。留出集保留给开发选型后的最终比较，本次不生成或运行留出调参实验。

## 严格审核发现与修复

| 问题 | 修复与证据 |
| --- | --- |
| 相似题跨开发/留出泄漏 | 先排相同和近似模板再划分；方向交换性质测试；v1–v3 不用于基线 |
| score_run 的题号路径越界 | 安全题号、重复检查、解析后根目录约束，拒绝越界链接和错位 checkpoint |
| 陈旧/混合运行成为基线 | 输入、配置、代码、模型、工具能力、评分器版本和全部输出文件绑定；篡改任意字段或 checkpoint 均拒绝 |
| 模拟成绩可能混为实测 | 明确 fixture/real 标签，配对时不能混用；模拟结果不能晋升策略 |
| reviewer 同人/缺项/旧包 | 两个不同评审身份、全量 review_id、packet 指纹校验，分歧保留 unknown |
| 反思开关未生效 | 关闭 reflection 禁止该请求，同时保留独立 critic；无额外隐式重试 |
| 验证器模糊文本成为票 | 独立校准开关与固定多 verdict、否定句、残句反例 |
| 符号化简忽略定义域 | 四个先失败的反例：x/x、约分消去奇点、根号平方、对数展开；修复后均 unknown |
| LaTeX 分式丢失括号 | 保留复合分子/分母优先级；归一化幂等和误判反例通过 |
| 符号大小写被错误合并 | x/X、a/A、Z/z、C1/c1 不自动等价；分类标签大小写兼容保留 |
| 极端科学计数法资源风险 | Fraction 转换前限制长度与指数，不构造十亿位整数 |
| 非有限用量及超大输出 | NaN/Inf 不进入统计；checkpoint 超过 2 MB 拒绝评分 |

自动判分规则已变化，因此旧评分报告不得直接当作新规则成绩；如比较旧运行，应保留原输出并在同一评分版本下重判。确定性修复与实验策略的效果分开记录。
